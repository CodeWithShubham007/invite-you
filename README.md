# Invite You — सुरभि संग विंध्या

A single-page tool to fill the "सेवा में" (guest name and address) box on the wedding card and download it as a PDF.

- Type the guest's name and address (in English or Hindi).
- Pick the card language: **English** or **हिंदी**. In Hindi mode, English text is converted automatically and you can correct it before downloading.
- Every downloaded card is saved in a list on the page (stored only in your browser) and can be exported as CSV.

Everything runs in the browser; `index.html` contains the card PDF itself.
